# シミュレータの手書きサンプル

`asm/*.s` は RV64 シミュレータのプリセットである。

教材の原則は「プリセットは `workbook/**/tests/` から生成し、アプリ側に手書きしない」
（[`../../design/webapps.md`](../../design/webapps.md) 1章）だが、ここは例外とする。
**概念を1つに絞った短いアセンブリと、わざと壊した不具合例**は他に出典がなく、
コンパイラの出力から切り出すこともできないためである。
参照実装の出力から作るプリセットは別に生成しており（`tools/build_web_examples.py`）、
そちらは「解答例を見る」を押すまで表示しない。

## 書き方

先頭のコメントで題名と説明を与える。ビルド時に読み取って一覧に出す。

```
# @title プロローグとエピローグ
# @desc 関数の出入りでスタックがどう動くか
#
# （ここから下は本文。画面にはそのまま表示される）
```

不具合例は題名を `【不具合例】` で始める。何が起きるかと直し方をコメントに書く。
対応する症状は [`../../workbook/docs/testing.md`](../../workbook/docs/testing.md)
の症状表に合わせる。
