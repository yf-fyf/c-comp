## ID とファミリの食い違いについて

`language_spec.md` は struct について、こう定めている。

> **struct 変数は宣言できるが、struct 値の代入・実引数・戻り値は不可**

つまり `q = p;` は、仕様が受け付けないと決めた形である。
ところがいまの実装はこれをエラーにせず、黙って受理して誤った答えを返す。
**仕様が禁じた形を実装が素通しさせている**——これは新機能の不足ではなく、
仕様と実装のずれであり、S 系の題材である
（[発展課題の索引](../README.md)の「S と L の判定基準」節）。
この回は、そのずれを「正しくコピーする」側へ倒して解消する
（仕様のこの行は、いずれ改訂の対象になる）。

**この回を S 系へ移すことは確定している**が、
**ディレクトリ名・URL・回 ID の振り直しは別の作業として後日行う**ため、
当面は `L1_struct/` のまま置いてある。分類は ID ではなく上の `仕様との関係` 欄で判断すること。
