## ID とファミリの食い違いについて

S 系は「仕様が意味を決めている構文の、仕様と実装のずれを埋める」回、
L 系は「仕様が対象外と決めた機能に、意味を自分で決めて足す」回である
（[発展課題の索引](../README.md)の「S と L の判定基準」節）。
この回は後者にあたる。仕様はポインタ同士の減算を「ない」と明示的に除外しており、
埋めるべきずれは存在しない。「差は要素いくつ分か」という意味は、この回で決めて足すものである。

**この回を L 系へ移すことは確定している**が、
**ディレクトリ名・URL・回 ID の振り直しは別の作業として後日行う**ため、
当面は `S3_ptrdiff/` のまま置いてある。分類は ID ではなく上の `仕様との関係` 欄で判断すること。
