# archive/

過去リリースの GitHub Pages 公開物を凍結したスナップショット。

**このディレクトリの中身はいかなる理由でも編集しない。** `v0.1.0/` は `origin/main`(リリース時の
GitHub Pages 公開物)から `git archive` で取り込んだビルド済み静的スナップショットである。
元原稿(`materials/`・`workbook/`)自体は `dev` の履歴上の当時のコミット付近に存在するはずだが、
その後の教材の改名・再構成(発展課題ID変更など)を経た現在の `dev` からその時点の資料サイトを
作り直すより、当時のビルド結果である `main` を凍結する方が確実で簡便なため、この経路を採った。
`v0.1.0.sha256` は取り込み時点の内容を保証するためのハッシュマニフェストで、
`tools/build_pages.py` がビルド時に照合する。

## 収録物

| 名前 | 公開日 | 出典 | 目的 |
|------|--------|------|------|
| `v0.1.0/` | 2026-07-29 | `origin/main`(`git archive` で取り込み) | 言語仕様 v2 適用前の資料・補助ウェブアプリ(`ast.html`/`sim.html`)。移行期の学習者向けの時限公開 |

`v0.1.0/` の内容はビルド当時のライセンス(教材本体 MIT)のまま。現行の教材ライセンス
(CC BY-NC-SA 4.0、T203で分離)とは異なる点に注意する。

## 時限措置であること

これは今学期の履修者が旧版資料から現行版へ移行し終えるまでの**時限的な**公開措置であり、
恒久機能ではない。撤去の権威ある期限とチェックリストは非公開リポジトリ
`../c-comp-design/tasks/TODO.md` で管理する。撤去手順の概要は
[`../design/maintaining.md`](../design/maintaining.md) の該当節を参照。

`tools/build_pages.py` の `ARCHIVE_SUNSET` を過ぎると、リリース実行時に stderr へ警告が出る
(リリース自体は失敗させない)。
